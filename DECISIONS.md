# Decisions & assumptions

Running log of judgment calls made during the autonomous build. Newest milestone at the bottom.

## Milestone 1 — scaffold

- **Stack:** TypeScript + Vite 6, Canvas2D (no PixiJS). Canvas2D with pre-rendered sprite frames is enough for 400 enemies + 200 projectiles and keeps the bundle tiny and dependency-free. Vite `base: './'` so the build works from any Pages sub-path.
- **Deploy:** GitHub Pages serves the `gh-pages` branch. The Actions workflow (`.github/workflows/deploy.yml`) builds on every push to `main` and force-publishes `dist/` there. The Pages REST API isn't reachable from my build environment, so I can't switch Pages to the "GitHub Actions" source; publishing to `gh-pages` works with either setting. `scripts/deploy.sh` does the same thing locally and is the fallback I use after each milestone.
- **Storage keys** are prefixed `ps_` so they never collide with Crank Crypt (`cc_`) on the same github.io origin. Every localStorage call is wrapped in try/catch (`src/core/storage.ts`).
- **Simulated trainer** (`src/trainer/sim.ts`): manual watts/cadence sliders, hold-to-sprint, and a bot. The bot follows the workout target with Ornstein–Uhlenbeck noise, random fades (to exercise the "missed target" path), auto-shifts virtual gears to hold ~90 rpm, and sprints when a boss shield is up. It emulates ERG lag (τ≈1.3 s) so ERG transitions look realistic. A crude HR model drives HR in sim so HR zones can be tested.
- **Gameplay power = 3 s average** (10 Hz ring buffer). Instant power is only used for the sprint shield meter and the sim.
- **Debug overlay**: backquote key, or `Settings → Debug overlay`. Alt+1..6 sets a time scale (x1/x2/x4/x8/x16/x0.25) for fast play-testing.

## Milestone 2 — core loop

- **View & scale:** world units ≈ CSS px at 760-unit view height. Camera leads ~70 units in the heading direction so you see what you're riding into.
- **Movement = power.** Speed = 225 × (0.35 + 0.65·min(p,1) + 0.5·clamp(p−1, 0, 0.8)) where p = 3 s power / FTP. You never fully stop (35% "coast") because a stalled rider in a horde game is just a death sentence.
- **Attack rate = power.** 55% at 0 W → 100% at FTP → 160% at 2.2×FTP. Cadence 85–100 rpm adds +10% crit.
- **Steering:** the bike always rolls; the D-pad *sets the heading* (8-way) and the heading persists after release, so tap-only controllers work. An alternative "turn" mode rotates the heading. Optional autopilot (also on whenever the bot rides) steers away from crowds and toward loot when you haven't steered for 1.2 s.
- **Death never ends the run** (the spec says missing targets never ends a run; I extended that to HP). At 0 HP you get knocked down for ~4.5 s, enemies are shoved back, you lose the current level's XP progress, then "Second Wind" revives you at 50% HP. Falls are tracked (achievements reward deathless runs).
- **Menus don't pause the world**; it runs at 6% speed and you're invulnerable while a level-up/chest/shop menu is open. The workout clock keeps running because your legs are.
- **XP curve** `xp(L) = 10 + 7L (+ a late-game term)`, tuned with bot runs so a 30-min run reaches level ~30–35.
- **Pools + spatial hash:** every entity type is preallocated, flagged dead during the frame and swap-compacted once at the end, so spatial-hash indices stay valid all frame. Queries de-duplicate with a per-enemy stamp (no Set allocations). Particles and damage numbers are struct-of-arrays.
- **Gems** get a gentle vacuum inside 2× pickup range, and gems past 900 merge into existing ones to cap counts.

## Milestone 3 — trainer, controller bridge, virtual gears, ERG

- **Ported from Crank Crypt, kept compatible:** same FTMS service/characteristics, the same picker filters (`FTMS`, `CPS`, `namePrefix: KICKR`, then accept-all fallback), the same Indoor Bike Data and Cycling Power parsers, the same control-point handshake (`0x00` request control → `0x07` start) and serialized write queue, the same `0x05` ERG and `0x11` simulation packets. Key bindings keep Crank Crypt's defaults (E/Q shift, Enter, A/D, F, Esc) so your BikeControl profile on the Pixel keeps working; Crank Crypt's "potion" key (F) is now Dash.
- **Improvements:** control-point responses are logged (you'll see if the KICKR rejects a command), the trainer reconnects on its own (4 tries with backoff) without a new picker, HR straps reconnect too, and a connection log is on the title screen.
- **Zwift Ride:** I did not talk to the Zwift Ride over BLE directly. Its protocol is proprietary, and your setup already bridges it through BikeControl on the Pixel as keyboard input. The title screen shows the last button received so you can confirm the bridge works. I also added Gamepad API support (D-pad, A/B/X, bumpers/triggers shift, Start pauses) in case a bridge presents itself as a gamepad.
- **Virtual gears (the Crank Crypt lesson):** 24 gears spanning 0.40×–2.6×FTP at 90 rpm (≈8.5% per gear). The default "ERG curve" mode sends `target = FTP × gear(g) × (rpm/90)^1.6`. The exponent is 1.6, not Crank Crypt's 3, so cadence changes power much less and hard efforts come from shifting up. A 150% sprint is gear ~19 at 90 rpm instead of ~115 rpm. The feel (exponent 1.3–2.5) is adjustable, and there's an optional "simulated grade" mode (FTMS 0x11, −2% to +9.5% by gear) that lets the KICKR do its own road feel. Writes are throttled (≥4 W change and ≥0.9 s apart) to keep the BLE queue clear.
- **ERG for targets:** every step with a target uses ERG at the band middle. The warm-up and cool-down ramp continuously. Sprints, the boss shield sprint and Free Ride use virtual gears. Settings → Interval resistance can switch target intervals to gears too, and that earns +25% Surge.
- **Pause relief:** pausing drops the trainer to ERG 45% so you aren't grinding a big gear or a VO₂ target while you fiddle with settings. Resuming restores whatever the workout wants.
- **Disconnects:** the run and the workout clock pause, and a modal offers Reconnect now / Continue with the simulator / End run while auto-reconnect runs in the background. Verified with a mocked Web Bluetooth FTMS device in headless Chrome (parsing, ERG writes per step, disconnect → pause → auto-reconnect → resume at the right ERG target, gear-mode writes).
- **Fonts are bundled** (@fontsource, latin subsets only, ~110 KB) so the UI looks right offline and in Bluefy without Google Fonts.

## Milestone 4 — workouts drive the waves

- **Templates** live in `src/data/workouts.ts`. There are 7: Endurance, Sweet Spot, Threshold, VO₂, Sprint Ladder, Over-Unders and Free Ride. Each `build(minutes)` scales to 20/30/45/60 min around a fixed frame: warm-up (4–10 min), main set, a 3-min boss block, then a 3–5 min cool-down "victory lap". The canonical sets (3×10 Sweet Spot, 2×20 Threshold, 5×3 VO₂) appear at 60 min. Shorter runs keep the rep count where possible and shorten the intervals; leftover minutes become a "Settle in" Z2 block. **Your 30-min Sweet Spot is 3×5 min at 88–94% with 2-min recoveries.**
- **Bands:** Sweet Spot 88–94%, Threshold 95–102%, VO₂ 110–120% ("hold 115% FTP" in the banner), Over-Unders 92–97% / 104–110%, Z2 65–75%, Tempo 76–86%, sprints ≥150%. The ±5% rule is a floor: a band narrower than ±5% around its middle is widened for the in-band check, so being in the shown band always counts.
- **Waves follow the template:** spawn rate ∝ (0.5 + 0.6·I²) where I is the target as a fraction of FTP, so a VO₂ wave is visibly denser than Z2. Step types pick the mix: elite waves (Sweet Spot, VO₂), siege (Threshold: ranged + shielded + healers), swarm (sprints, Overs), calm (warm-up, recovery, cool-down). Free Ride uses your rolling 3-minute power as I.
- **Surge:** builds while in band (faster during work intervals), drains outside it, and adds up to +50% damage and XP. At 100% it triggers **Overdrive**: a nova and double damage for 8 s. Gears-for-intervals mode gives +25% Surge gain; Sora (TT) gets +50%.
- **Missing the target:** after 6 s below the band, director pressure goes up a notch (more spawns, a higher cap, +25% enemy speed and +30% damage per full step, up to 2.2×), with a banner telling you the watts to get back to. Pressure decays while you're back in band. It never ends the run.
- **Recovery waves** open the pit-stop shop (heal, mystery upgrade, reroll, chest) or drop a chest. The cool-down drops a chest too. Shop prices are paid in run gold, which is otherwise banked for permanent upgrades, so you trade now against later.
- **Boss:** 8 s countdown in gears ("shift up"), then the boss spawns with a hex shield that only sprint power breaks. The shield drains at `clamp((P/FTP − 1.2)/0.3, 0, 1.6)/24` per second: about 24 s at 150% FTP and 15 s at ≥168%, and nothing below 120%. That fits the 15–30 s all-out window. Uses instantaneous (0.6 s) power so the meter reacts. If 30 s pass, the shield regrows to 55%; you get 40 s of ERG recovery and a second sprint. Once it breaks, ERG goes to 78% for the fight. Boss HP is based on your **recent DPS** (last ~60 s) so it lasts 60–90 s whatever your build. The workout clock holds the boss block open (overtime) for up to 2.5 min; after that the boss flees. Killing it skips straight to the victory lap, and the cool-down absorbs the remaining boss time so the planned workout length is unchanged.
- **Mini-bosses** spawn at the start of steps flagged `mini` (mid-set), one per run length tier, in the arena's preferred order.
- **Arena hazards** start after minute 2 (every 28–48 s, not in calm/boss waves): Sakura rockslides, Neon laser grids, Volcano geysers that leave burning ground. They're telegraphed and they hurt enemies too.
- **Physics sub-steps:** the loop sub-steps at ≤34 ms so the debug time-scale (used for bot play-tests at 8×) doesn't break collisions or pickups.

## Milestone 5 — full content

- **11 weapons, 11 evolutions, 13 passives** (`src/data/weapons.ts`). Every base weapon has an evolution (spec asked for ≥6). Evolution rule matches Vampire Survivors: weapon at max level (6) + its paired passive at any level, then the next chest evolves it. Pairs: Darts+Cadence Sensor→Presta Storm, Shuriken+Aero Helmet→Wheel of Ruin, Whip+Chain Lube→Derailleur Reaper, Cannon+CO₂→Howitzer, Bell+Chamois→Cathedral Chime, Bidon+Electrolytes→Tsunami, Drone+Power Meter→Domestique Swarm, Lightning+Carbon Rims→Thunder Tubular, Boomerang+Lucky Socks→Grand Tour, Laser+Caffeine Gel→Hyper Beam, Trail+Sealant→Inferno Draft. All 11 verified by `scripts/evo.py`.
- **10 enemy behaviours**: swarm, chase, heavy chase, charger, ranged, splitter (+ children), shielded (frontal shield blocks projectiles), exploder, phaser (blinks in and out), healer. Elites are any enemy with an elite flag (bigger, gold outline, more HP, guaranteed chest chance).
- **3 mini-bosses and 3 final bosses**, one of each per arena, each with its own attack set (slam, rock fall, spiral bullets, dashes, laser sweeps, summons, shock rings, charges).
- Canvas `ellipse()` throws on negative radii in Safari/WebKit. Every zone draw now clamps radii (found by a crash during shrinking telegraphs).

## Milestone 6 — meta-progression

- **18 permanent upgrade nodes** (`src/data/meta.ts`), cost `base·(rank+1)^1.5`, with a free full refund. Gold banks at the end of every run, quit runs included (you still rode).
- **38 achievements** (`src/meta/achievements.ts`), data-driven: each lists the events it listens to and a test. They pay 15–250 gold. Unlocks: Yuki (5th rider) unlocks when you evolve any weapon. Neon Criterium unlocks when you beat the Oni Shogun; Volcano Col unlocks when you beat the Neon Leviathan. Kai, Mira, Sora and Ren (sprinter, climber, TT and all-rounder) are available from the start, so the spec's 4 riding styles are always playable.
- **Lifetime stats** (`src/meta/progress.ts`): kJ, time ridden, runs, wins, kills, best 1/5/20-min power (from the 1 Hz recording, rolling windows), peak power, fastest shield break, best compliance, per-template, per-boss, per-rider and per-arena counts, plus the last 30 runs with their auto-titles.
- **Save backup:** export goes through the share sheet (iPad: Save to Files) with a download fallback, plus copy-to-clipboard. Import accepts a file or pasted text and validates it. Reset needs two taps. I avoided `window.confirm` everywhere because modal dialogs stall Web Bluetooth callbacks in Bluefy.
- **Balance pass (bot play-tests at 16×):** boss HP was sized from total DPS, which mostly measures AoE damage across the horde, so bosses outlived the overtime window. It's now `max(base, 17×recent DPS)`, and aimed weapons alternate their target between the nearest enemy and a vulnerable boss within range. Enemy damage grows 2.2%/min (was 3%), hits are ×0.85, and post-hit invulnerability is 0.85 s. Exploders do less damage, and Neon/Volcano HP multipliers dropped to 1.25/1.5. Cold-save Volcano is still brutal (≈17 falls for the bot). With a mid-game upgrade set it's 0 falls and a boss kill, which is the intended curve.
- **Bot realism:** the autopilot now dodges telegraphed slams, rockslides, geysers and charged laser lines, and circles a vulnerable boss at ~250 units instead of fleeing it. Lesson learned: run headless play-tests one at a time. Two at once starve each other's frames and roughly triple the falls.
- Stacked menus now hide the screen beneath them. Achievement toasts are suppressed for end-of-run unlocks because the post-run screen lists them.
